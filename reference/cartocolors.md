# CARTOColors database

A dataset containing the information about the CARTOcolor palettes.
Source:
https://github.com/CartoDB/CartoColor/blob/5302a3d7245595251ea5dd90fc09efcb8d3254fb/cartocolor.js.

## Usage

``` r
cartocolors
```

## Format

A data frame with 34 rows and 13 variables:

- Name: palette name

- Type: palette type

- `n2` to `n12`: list columns containing the stored colors for each size
