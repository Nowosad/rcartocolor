# CARTOColors database metadata

A dataset containing the information about the CARTOcolor palettes.
Source:
https://github.com/CartoDB/CartoColor/blob/5302a3d7245595251ea5dd90fc09efcb8d3254fb/cartocolor.js.

## Usage

``` r
metacartocolors
```

## Format

A data frame with 34 rows and 5 variables:

- Name: palette name

- Type: palette type

- Min_n: minimal number of colors in a given palette

- Max_n: maximal number of colors in a given palette

- Colorblind_friendly: is the palette colorblind friendly?
